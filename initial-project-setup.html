Open — needs a decision

Nothing here blocks day-to-day work; each one just needs a call made before it can close.

Protect the main branch blocked

GitHub won't apply branch protection to a private repo on the free plan. Needs either a GitHub Pro upgrade or making the repo public. The rule itself is already decided: no required reviews, admin can bypass, no required status checks until CI exists.

Pick the tech stack

Nothing is chosen yet — language, framework, dependencies. Until it is, the lint hook has nothing to detect, and most of this project is still a plan.

Add a CI workflow

Depends on the stack decision. Once a test suite exists, add a GitHub Actions workflow that runs it on every push, then require it to pass before merging into main.

Revisit PR review rules

Zero approvals are required right now, because GitHub won't let you approve your own pull request. Add a required-approval count once a second collaborator joins.
