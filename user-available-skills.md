# User Available Skills

Append-only log of skills available for use in this project. Entries are **never removed**, even after a skill has been used — see CLAUDE.md for the rule that keeps this file growing.

- **superpowers** — Core skills library for Claude Code: TDD, debugging, collaboration patterns, and proven techniques. (https://github.com/obra/superpowers)
- **ponytail** — Lazy senior dev mode: the smallest change that fully solves the task, and a reply a busy human understands in one read. Levels: lite, full, ultra.
- **ui-ux-pro-max** — Searchable UI/UX design intelligence: style/color/typography/UX-rule database and design-system generator. Used to plan `initial-project-setup.html`.
- **frontend-design** — Guidance for a distinctive, non-templated visual identity when designing a page. Used to style `initial-project-setup.html`.
